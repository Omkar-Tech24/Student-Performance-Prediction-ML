# Student-Performance-Prediction-ML
# Student Performance Prediction using Machine Learning

## Objective
To predict whether a student will pass or fail based on study hours, attendance, and previous marks.

## Technologies Used
- Python
- Pandas, NumPy
- Scikit-learn

## Algorithm Used
- Decision Tree Classifier

## Result
The model predicts student performance with good accuracy and supports real-world predictions.
